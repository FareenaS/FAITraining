An API is a function or a set of functions that will perform some complex task and users will consume the API without knowing the internals of it. However, they must be knowing about the functionality of the API but not the implementation logic of that API. 
ADO.NET, FileIO, MultiThreading are some of the APIs of .NET that we use for our App Development. 
APIs created to be used in a Web Environment are called as WebAPIs. It is the .NET Framework for creating RESTFull Services. 
What is a RESTFul Service?
A Service that is accessible using HTTP protocol and its methods like GET, PUT, POST and DELETE to get the data in a specific format from the Storage(PERSISTENCE) Layer. Most of the time, the data format will be either XML or JSON. JSON is the prefered format. JSON stands for JavaScript Object Notation, representing data in the form of JS Objects. They are basically Text. XML is also text. Both are self descriptive data.   
The methods determine the flow of the data b/w the server and the client. 
GET->Extract the data from the server to the client(browser)
POST->Add the data into the server from the client
PUT->Modify the data into the server from the client. 
DELETE->Delete the data in the server from the client. 

REST Full services only share the data, not the presentation. The data will be in the format of XML or JSON. 
.NET uses MVC Architecture for creating Web APIs. Here we will have controllers and Models but no Views. The REST API will have only data transfer, not the Presentations. The Views can be generated by the respective Client Technologies. 

All Controllers in Web API are derived from System.Web.Http.Controller.
